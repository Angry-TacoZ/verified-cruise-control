# RSA ADAS reference (Milestone 1 deliverable)

This document will hold the human-readable, source-cited,
structured reference extracted from the Road Safety Authority
"Advanced Driver Assistance Systems (ADAS)" guide, September 2026.

Scope: general automotive ADAS knowledge (definitions, functional
distinctions, illustrative symbol cues, limitations). It is **not**
manufacturer equipment data and never overrides the versioned
manufacturer catalog in `backend/audits/adas_catalog_v1.json`.

Status: scaffold — content lands with Milestone 1
(`backend/audits/rsa_reference.json` + loader + unit tests).
